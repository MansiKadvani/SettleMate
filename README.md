# 🎓 SettleMate – The Student Relocation Companion

> **Helping students settle into a new city with ease.**

---

## 📌 About The Project

Moving to a new city for college can be overwhelming and chaotic. **SettleMate** is an all-in-one student relocation web platform designed to solve the real, everyday challenges faced by students moving for higher education. 

Instead of juggling multiple disconnected apps for housing, roommate searching, and buying furniture, **SettleMate** brings everything into a single, cohesive ecosystem.

---

## ✨ Key Features

* **🏠 Verified Accommodation Search:** Find verified PGs, hostels, and rental flats filtered by budget, distance from college, amenities, and preferences.
* **🤝 Smart Roommate Finder:** Find compatible roommates based on sleeping schedule, study habits, dietary preferences, and budget.
* **🛒 Peer-to-Peer Marketplace:** Buy and sell second-hand study materials, calculators, mattresses, cycles, and appliances directly with fellow students.
* **🛋️ Essentials Rental:** Flexible monthly rentals for essential room furniture and electronics (mini-fridge, induction stove, study table, etc.).
* **🛡️ Complaint & Verification System:** Built-in safeguards to report fake listings, fraudulent posts, and safety issues.
* **📊 Role-Based Dashboards:** Custom user interfaces for **Students**, **Property Owners**, and **Admins**.

---

## 👥 User Roles & Capabilities

| Role | Key Capabilities |
| :--- | :--- |
| **👨‍🎓 Student** | Search housing, request roommates, buy/rent essentials, save wishlists, write reviews, report issues. |
| **🏠 Property Owner** | Post listings, upload photos, manage room availability, handle student inquiries. |
| **👨‍💼 Admin** | Verify listings, moderate reviews, handle complaints, view platform analytics. |

---

## 🛠️ Tech Stack

* **Framework:** ASP.NET Core MVC
* **Database Access:** ADO.NET
* **Database:** Microsoft SQL Server
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
